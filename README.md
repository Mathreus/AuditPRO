<h1>📊 Automação de Testes de Auditoria e Análise de Dados</h1>

<hr>

<h2>🎯 Sobre o Projeto</h2>

<p>
Este repositório reúne testes de <strong>Auditoria Interna</strong> desenvolvidos com
<strong>SQL e Python</strong>, com foco na automação de análises, identificação de exceções
e avaliação de riscos a partir de grandes volumes de dados.
</p>

<p>
O objetivo é aumentar a <strong>eficiência</strong>, <strong>abrangência</strong> e
<strong>consistência</strong> dos trabalhos de auditoria por meio de consultas estruturadas,
automações e técnicas de análise de dados.
</p>

<hr>

<h2>🚀 Principais Objetivos</h2>

<ul>
  <li>
    <strong>Automação de Testes de Auditoria:</strong>
    desenvolvimento de consultas e scripts para execução recorrente de testes,
    reduzindo atividades manuais e aumentando a eficiência das análises.
  </li>

  <li>
    <strong>Análise de Grandes Volumes de Dados:</strong>
    utilização de SQL, Python e BigQuery para análise de transações,
    movimentações, estoques e outras bases corporativas.
  </li>

  <li>
    <strong>Identificação de Exceções:</strong>
    criação de regras para detectar desvios, inconsistências e situações
    que possam representar riscos para a organização.
  </li>

  <li>
    <strong>Análise Avançada de Dados:</strong>
    aplicação de técnicas estatísticas e modelos de Machine Learning
    para identificação de padrões, tendências e anomalias.
  </li>

  <li>
    <strong>Visualização dos Resultados:</strong>
    estruturação de indicadores e dashboards para facilitar a interpretação
    das análises e apoiar a tomada de decisão.
  </li>
</ul>

<hr>

<h2>⚙️ Funcionalidades</h2>

<ul>
  <li>Execução de testes automatizados de Auditoria Interna;</li>
  <li>Consultas SQL aplicadas a diferentes processos e bases de dados;</li>
  <li>Integração com Google BigQuery;</li>
  <li>Tratamento e análise de dados utilizando Python;</li>
  <li>Identificação de padrões, exceções e possíveis irregularidades;</li>
  <li>Desenvolvimento de modelos de Machine Learning aplicados à auditoria;</li>
  <li>Construção de indicadores e visualizações em ferramentas de Business Intelligence;</li>
  <li>Validação das análises com informações provenientes do SAP S/4HANA.</li>
</ul>
